# Pokémon Gold & Silber '97 Reforged — Deutsche Lokalisierung

Deutsche Lokalisierung von **Pokémon Gold & Silber 97 Reforged**, einem Rom-Hack, der versucht, eine „fertige" Version der Spaceworld-97-Demo zu rekonstruieren.

## Über das Projekt

Die Spaceworld-97-Demo gab einen frühen Einblick in Pokémon Gold & Silber und enthielt zahlreiche Pokémon, Karten und Ideen, die es nie in das fertige Spiel schafften. Dieses Projekt ist die deutsche Fassung des "Reforged" Hacks und bringt die verlorene Vision in einer spielbaren Form auf Deutsch heraus.

## Ursprüngliche Werke

Dieses Projekt basiert auf der Arbeit anderer und wäre ohne sie nicht möglich:

- **[Gold '97 Reforged](https://github.com/SoupPotato/gold97)** von SoupPotato — englisches Original dieses Reforged-Hacks, auf dem diese Lokalisierung direkt aufbaut.

## Patch anwenden

Im Repository wird ein **IPS-Patch** oder **BPS-Patch** bereitgestellt (siehe [Releases](../../releases)). Dieser muss auf eine unveränderte **englische Pokémon-Crystal-ROM** angewendet werden (das Projekt basiert technisch auf pokecrystal).

Am einfachsten geht das direkt im Browser mit dem **[Online IPS Patcher von Marc Robledo](https://www.marcrobledo.com/RomPatcher.js/)**:

1. Als „ROM file" die originale englische Pokémon Crystal ROM auswählen.
2. Als „Patch file" die hier bereitgestellte `.ips` oder `.bps`-Datei auswählen.
3. Auf **Apply patch** klicken und die gepatchte ROM herunterladen.

Die gepatchte ROM lässt sich anschließend in jedem gängigen Game-Boy-Color-Emulator (z.B. BGB, SameBoy, mGBA) starten.

> Hinweis: Die originale ROM wird aus rechtlichen Gründen nicht mitgeliefert und muss selbst beschafft werden.
